# Getting help

- Something broken: open a [bug report](https://github.com/ElDiablo66/anonymous-vrx-app/issues/new?template=bug_report.yml). Say which version you run (Settings, About) and what you clicked.
- An idea: open a [feature request](https://github.com/ElDiablo66/anonymous-vrx-app/issues/new?template=feature_request.yml).
- A question about how something works: the [README](README.md) covers install, privacy, where data lives and known limits. If it doesn't answer you, open an issue and say it's a question.
- A security problem: follow [SECURITY.md](SECURITY.md) instead, so it stays private.

Leave your VRChat password, codes and cookie out of everything you post. For screenshots, switch on "Hide names and pictures" (Ctrl+Shift+H) first so your friends' names and pictures are covered.

The installer is blocked or SmartScreen warns: it isn't code signed yet. In the browser choose Keep, then in SmartScreen choose "More info" and "Run anyway". Compare the file's SHA-256 with the one on the release page if you want to be sure it's the real one.

This is a one-person project, so replies can take a few days.
